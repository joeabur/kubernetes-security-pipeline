# Security Policy

## Scope

This repository is a security engineering demonstration. The secure manifests are hardening examples; the `intentionally-vulnerable` directory is a negative test lab and must not be deployed to a shared cluster.

## Reporting

Do not open a public issue for a suspected vulnerability in a real deployment. Use GitHub private vulnerability reporting when enabled, or contact the repository maintainers through the organization security channel. Never include credentials or personal data in a report.

## Supported versions

Only the default branch is maintained. Dependencies and GitHub Actions are reviewed by Dependabot and pull request checks.

## Response targets

Critical: triage within 24 hours. High: triage within 3 business days. Medium and low: triage during the next maintenance cycle. These are demonstration targets, not a service-level commitment.
